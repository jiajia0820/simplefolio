## 本地运行

本轮验证环境为 Node.js 24.14.1、npm 11.11.0。
`.nvmrc` 已对齐该 Node.js 版本。

```powershell
npm ci
npm start -- --host 127.0.0.1
```

浏览器打开终端输出的本地地址，默认端口为 1234。

## 构建

```powershell
npm test
npm run build
```

测试覆盖模板结构、占位状态、真实图片排版、资源路径、隐私检查和动画兜底。
生产构建结束后自动运行 `scripts/verify-build.cjs`，
检查五个 SVG 取景窗口、七个项目与头像图片、六个画廊图片和两个完整的视频文件。
产物位于被 Git 忽略的 `dist/`。
本轮未推送 GitHub，未配置远程部署。

原模板的 Parcel 2.8.2 在当前中文路径下，缓存阶段会出现
`Error opening directory`。运行脚本加入 `--no-cache` 避开该问题，
没有升级或替换原有依赖。代价是再次构建时不复用磁盘缓存。

原仓库自带面向 `main` 分支的 GitHub Pages 工作流，本轮保留且未执行。
后续发布前，需要核对部署分支、项目页资源子路径和内容公开范围。

检查生产产物时，先停止正在运行的 `npm start`，再运行：

```powershell
npm run build
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

在浏览器打开 `http://127.0.0.1:4173/`。
开发预览也会写入 `dist/`，不要在生产验收期间同时运行。

## Git 回退与比较

工作分支：`codex/simplefolio-v1`。

| 标签                     | 内容                                           |
| ------------------------ | ---------------------------------------------- |
| `v0.0.0-template`        | 完全未改动的 Simplefolio 模板                  |
| `v0.1.0-shell`           | 完成校验的个人网站第一版                       |
| `v0.1.1-template-design` | 严格恢复原模板视觉的历史版本                   |
| `v0.1.2-real-media`      | 保留模板设计，接入真实照片和项目截图的历史版本 |
| `v0.1.3-project-demos`   | 接入前两个项目演示视频与源码链接的历史版本     |

先确认工作区状态：

```powershell
git status
```

在新的本地分支查看原模板，不覆盖现有版本：

```powershell
git switch -c review/template v0.0.0-template
```

返回第一版工作分支：

```powershell
git switch codex/simplefolio-v1
```

比较两个版本：

```powershell
git diff v0.1.2-real-media v0.1.3-project-demos
```

以上操作要求先保存或提交手头的改动。
不要用强制重置覆盖未保存的修改。
