2. 视频、源码、简历的待补充状态。
3. 本地资源与页面内锚点。
4. 不包含私人电话、学校邮箱或本地私有材料路径。
5. 占位提示沿用原 CTA 字号。
6. 动画 CDN 不可用时，正文恢复为静态可读状态。
