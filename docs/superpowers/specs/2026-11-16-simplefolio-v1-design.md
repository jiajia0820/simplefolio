# Simplefolio 第一版范围

## 最新约束：2026 年 11 月 17 日

用户明确要求不要改变原模板设计。
当前版本恢复原模板示例图片、按钮元素和页脚结构，撤回定制占位图与附加按钮样式。
所有 SCSS 以 `v0.0.0-template` 为基准保持一致。
真实视频、头像和源码到位后仅替换相应内容，不自行调整设计。
以下初始范围中的占位素材说明以本节为准。

## 已确认的需求

2026 年 11 月 16 日，用户明确要求第一版只套用其 fork 的 Simplefolio。
保留原有视觉和单页结构，搭好框架后再评估后续迭代。
视频与项目源码尚未提供，需要预留位置并建立 Git 回退标记。

## 实现范围

- 保留 Hero、About、Projects、Contact、Footer 的顺序和布局。
- 保留模板的青绿色、白底、留白、Bootstrap 栅格与原有动画。
- 依据本次提供的主版 PDF 填写姓名、教育概况、项目摘要。
- 沿用原模板的三个项目位，分别展示智家清单、经营分析问数 Agent、智慧病区巡检实习实践。
- 图片采用明确标记的占位图，不使用他人照片或伪造产品截图。
- 视频、源码和公开版简历未接入前，显示不可点击的待补充状态。
- 不增加导航、详情页、播放器、博客、表单、CMS 或新框架。
- 增加动画脚本不可用时的静态可读兜底。
- 运行与构建禁用 Parcel 磁盘缓存，兼容当前 Windows 中文目录。

## 内容和隐私

主版 PDF 优先于较早的笔记版本，简历库仅用于补充背景。
不复制笔记正文、私有维护段落、手机号、邮箱、证件照或原始 PDF。
不公开具体企业协议方案、未确认的企业披露指标或内部文件。
只保留用户已提供的公开 GitHub 主页入口。
网站内容仅在本地预览；本轮不推送、不部署。

## Git 检查点

- `v0.0.0-template`：未经个性化的模板，基于 `af03c0c`。
- `codex/simplefolio-v1`：第一版工作分支。
- `v0.1.0-shell`：完成验证的第一版框架。

## 实施与验收计划

1. 克隆并检查模板、内容来源和许可证，标记原版。
2. 按原模板替换文案和占位素材，保留布局。
3. 安装锁定依赖，运行格式检查、生产构建与内容检查。
4. 在浏览器核对桌面和手机视图、锚点与资源加载。
5. 进行只读代码复核，记录验证结果。
6. 提交并标记第一版，提供预览和回退说明。

## 后续迭代边界

后续获得视频、源码地址、公开简历、头像或联系方式后，再单独确认接入。
Dopefolio 的布局和独立案例页不进入本次版本。
