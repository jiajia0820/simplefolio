# 已批准的真实图片接入

## 用户要求

用户确认采用第 4 张生活照，并提供经营分析问数 Agent 截图、机器人照片、
智家清单的四张实机截图，允许选择适当数量拼图或调整图片摆放方式。
保持横向展示，不改变原模板设计。

## 实施边界

- 只替换 About 与三个 Projects 展示位中的示例素材。
- 主体 HTML 区块、Bootstrap 栅格、全部 SCSS、配色、字体、间距及动画配置保持原样。
- 选择智家清单首页、需求测评、方案预算三张图，横向并排于一个 16:9 容器内。
- 方案详情图保留备选，不强行挤入主展示位。
- 使用代码原生的 SVG 图片排版，完整保留原图及截图文字，不生成或重绘图像。
- 生活照只通过方形窗口取景，不修改原始照片。
- Agent 与机器人图等比适配横向区域，保留完整内容。
- 视频、项目源码与公开版简历链接继续保持待补充状态。
- 不自动推送、部署或上传图片。

## 验收

1. 生活照主体位于原来的方形头像中，人物五官保持原样。
2. 图片分别对应三个项目，智家清单为三张完整界面的横排。
3. 构建后的 SVG 图片引用全部指向实际产出的资源。
4. 全部原模板样式和动画参数与 `v0.0.0-template` 一致。
5. 自动测试、生产构建、桌面与手机浏览器核对通过。
6. 以新提交及 `v0.1.2-real-media` 标签保留回退点，旧标签不移动。
